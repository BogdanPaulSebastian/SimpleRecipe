# SimpleRecipe
**This is a re-upload of my "Simple Recipe" android app that I made 4 years ago**

It has been taken off play store after google policy changes - so I'm making it public maybe someone will learn from it.

# Concept
"Simple Recipe" is a native android application that helps you lower food waste & find delicious recipes; Search by leftover ingredients, filter by diets, allergies and food
restrictions.

note: This was more useful back then when you couldn't ask AI to make you a recipe yet :)

### How it works
Input some ingredients you have in the search bar and select what filters you want and hit search. The app will fetch all recipes containing those ingredients and matching your specific filters!
